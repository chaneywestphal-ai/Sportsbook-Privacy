Privacy Policy

Sports Betting Intel GPT

Last updated: March 25, 2026

Overview

Sports Betting Intel GPT ("the GPT") is a custom GPT built on OpenAI's ChatGPT platform. It retrieves publicly available sports data including scores, matchups, news, and betting odds to help users stay informed. This privacy policy explains how the GPT handles user information.

Data Collection

This GPT does not collect, store, or share any personal data. Specifically:

  • No personal information is collected (name, email, location, etc.)
  • No conversation data is stored by the GPT creator
  • No cookies or tracking technologies are used
  • No analytics or telemetry data is gathered
  • No user data is sold, shared, or transferred to any third party

Third-Party APIs

This GPT connects to the following external data sources to fulfill requests:

  • ESPN API — Public, unofficial endpoints for scores, news, and team data. No authentication or user data is sent.
  • The Odds API (the-odds-api.com) — Used to retrieve real-time betting odds. Only a server-side API key is sent with requests. No user information is transmitted.

These services have their own privacy policies. The GPT only sends sport-related query parameters (e.g., sport type, date) to these APIs — never any user-identifying information.

OpenAI Platform

This GPT runs on OpenAI's ChatGPT platform. Your conversations are subject to OpenAI's Privacy Policy and Terms of Use. The GPT creator has no access to your conversations with the GPT.

Children's Privacy

This GPT is not directed at children under the age of 13. No data is knowingly collected from minors.

Changes to This Policy

This privacy policy may be updated from time to time. Any changes will be reflected on this page with an updated revision date.

Contact

If you have questions about this privacy policy, you can reach the GPT creator through the ChatGPT GPT listing page.
